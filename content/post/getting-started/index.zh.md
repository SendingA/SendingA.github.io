## 概览

1. 面向 Hugo 的 Wowchemy 网站构建工具及其入门模板，专为专业创作者、教育工作者以及团队和组织设计，也可以用于创建任何类型的网站
2. 模板可以根据你的需求修改和定制。它适合希望掌握自己的数据与网络身份，同时便捷地从**无代码方案（使用 Markdown 写作、用 YAML 参数定制）**开始，并保留**日后通过 HTML 和 CSS 深度个性化**能力的用户
3. 你可以借助数百种插件与集成，使用喜爱的工具和应用，加快工作流程、与读者互动，并实现更多功能

## 功能

- **页面构建器**——使用[**组件**](https://docs.hugoblox.com/page-builder/) 和[**元素**](https://docs.hugoblox.com/content/writing-markdown-latex/)
- **编辑各种内容**——博客、论文、演讲、幻灯片、项目等！
- 通过以下工具**创建内容**： [**Markdown**](https://docs.hugoblox.com/content/writing-markdown-latex/), [**Jupyter**](https://docs.hugoblox.com/import/jupyter/), or [**RStudio**](https://docs.hugoblox.com/install-locally/)
- **插件系统**——完全可定制的[**配色与字体主题**](https://docs.hugoblox.com/customization/)
- **展示代码与公式**——代码高亮和 [LaTeX 数学公式](https://en.wikibooks.org/wiki/LaTeX/Mathematics)支持
- **集成**—— [Google Analytics](https://analytics.google.com), [Disqus 评论](https://disqus.com), 地图、联系表单等！
- **美观的网站**——简洁清新的单页设计
- **出色的 SEO**——帮助用户通过搜索引擎和社交媒体找到你的网站
- **媒体相册**——在可定制的相册中展示带说明的图片与视频
- **移动端友好**——适配移动设备，在各种屏幕上都有良好效果
- **多语言**——提供 34 种以上语言包，包括英语、中文与葡萄牙语
- **多用户**——每位作者都有独立的个人资料页
- **隐私工具包**——协助满足 GDPR 要求
- **脱颖而出**——用动画、视差背景和滚动效果为网站增添活力
- **一键部署**——无需服务器或数据库，只需文件。

## 主题

Wowchemy 及其模板内置**自动日间（浅色）与夜间（深色）模式**。访客也可以选择偏好的模式——点击[演示网站](https://academic-demo.netlify.com/)右上角的月亮图标即可体验！网站管理员还可以在 `params.toml` 中关闭日夜模式。

为网站[选择美观的**主题与字体**](https://docs.hugoblox.com/customization)。主题支持全面定制。
